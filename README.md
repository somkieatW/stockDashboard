# Smart Fried Food Shop Management & Dashboard Backend

A Node.js/Python backend and Supabase PostgreSQL integration for the Smart Fried Food Shop management dashboard.

## Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Chart.js
- **Backend**: Python Flask, CORS
- **Database**: PostgreSQL (Supabase)

## Setup & Run Instructions

1. Install Python dependencies:
   ```bash
   pip install flask flask-cors psycopg2-binary
   ```
2. Initialize database schema & demo records:
   ```bash
   python init_db.py
   ```
3. Run the development server:
   ```bash
   python app.py
   ```
4. Open the application in your browser:
   - **http://localhost:5000**
